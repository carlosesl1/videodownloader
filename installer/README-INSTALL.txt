VIDEO RADAR 1.0.0 - PACOTE PARA DESENVOLVEDORES

Este ZIP e a alternativa transparente ao instalador principal.

1. Execute Helper\Instalar-Video-Radar.cmd.
2. Abra chrome://extensions, edge://extensions, brave://extensions ou
   vivaldi://extensions.
3. Ative o Modo do desenvolvedor.
4. Clique em Carregar sem compactacao e selecione a pasta Extension deste ZIP.
5. Confirme que o ID exibido e cakpfifpfmbdcilimpedanglnopnmckg.
6. Fixe o Video Radar na barra e use Buscar videos em uma pagina autorizada.

Use o Video Radar somente para midia propria, em dominio publico, sob licenca
que permita download ou com autorizacao explicita. O projeto nao contorna DRM,
login, conteudo privado ou restricoes de acesso.

Para a instalacao comum, prefira VideoRadar-Setup-1.0.0-Windows-x64.exe.
